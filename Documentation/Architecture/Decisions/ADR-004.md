# ADR-004 — Versioned clinical rendering and platform adapters
Status: Proposed
Date: 2026-09-10
Related requirements: FOUND-007, FEAT-007, FEAT-009
Related tasks: TASK-012, TASK-013, TASK-014
Decision owner/acceptance evidence: project owner / pending

## Context
Clinical content must stay separate from print layout; platform matrix and legal templates are unresolved.

## Options
A. Server PDF renderer gives centralized reproducibility but needs protected artifact handling. B. Browser HTML/print CSS simplifies web preview but varies across browsers. C. Native rendering/print adapters cover device workflows with separate verification.

## Proposed decision
Accept snapshot-to-renderer application port and platform print/export adapters in principle; concrete renderer/format remains deferred until FIND-003/004 decisions and feasibility evidence. Template and issued-content versions remain attributable. Define cancellation/failure explicitly; no claim of physical print completion without evidence.

## Consequences and validation
Use long synthetic prescription/certificate fixtures for content, pagination and provenance; validate web and native separately. Resolve storage/cache/retention/access of artifacts under FIND-006 before persisting artifacts.
No implementation or deletion is approved by this record. See [baseline](../BASELINE.md) and [findings](../../Assessment/INITIAL_ASSESSMENT.md).
